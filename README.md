# Día 9 — Modularización del gestor de tareas 🧩

Este repositorio forma parte de mi reto personal **100 días aprendiendo a programar**.

En el Día 9 he reorganizado mi gestor de tareas utilizando funciones para separar responsabilidades y mejorar la estructura del programa.

---

## 📚 Qué he aprendido

- Dividir un programa en funciones
- Separar responsabilidades (menú, añadir tarea, mostrar tareas)
- Pasar parámetros entre funciones
- Crear una estructura más limpia y profesional
- Pensar en organización del código

---

## 🚀 Proyecto: Gestor de tareas modular

El programa ahora incluye:

- `mostrar_menu()`
- `añadir_tarea()`
- `mostrar_tareas()`
- Un bucle principal que controla la aplicación

Esto hace que el código sea:
- más claro
- más reutilizable
- más fácil de mantener
- más cercano a un proyecto real
